PRIVATE BY DEFAULT

Metadata, not content.

The protected local UI can use limited tool/context metadata needed for the product. Public/share artifacts are much stricter.

  • No prompts or responses in public aggregate
  • No source code or terminal logs
  • No raw commands or process IDs
  • No full filesystem paths
  • No credentials, API keys or cookies
  • No account identity or device name in public aggregate
