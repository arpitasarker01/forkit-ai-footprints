CONFIDENCE IS A FIRST-CLASS FIELD

Forkit does not flatten uncertainty into “logged.”

DIRECT

Observed in a source record.

Example: an SAP write event or signed tool request.

SUPPORTED

Corroborated across sources.

Example: identity plus tool evidence agrees on the same principal and object.

INFERRED

Correlated, not directly proven.

Example: time/resource/business-object correlation without a shared transaction ID.

CONFLICTING

Sources disagree.

Example: agent trace names one identity while the business-system audit shows another.

MISSING

Required evidence is absent.

Absence remains visible instead of being silently filled in.
