# Support

Forkit AI Footprints is a free, open-source project maintained on a
best-effort basis. The supported release is the latest npm version on Apple
Silicon macOS.

## Before requesting help

Update the app and collect the non-sensitive version and readiness output:

```bash
npx --yes forkit-ai-footprints@latest
forkit-ai-footprints --version
forkit-ai-footprints doctor
```

Do not post prompts, responses, credentials, account identity, device names,
full paths, private model names, or unredacted terminal output.

## Where to ask

- Use the [bug report](https://github.com/arpitasarker01/forkit-ai-footprints/issues/new?template=bug_report.yml)
  for reproducible behavior that differs from the documented release.
- Use the [support question](https://github.com/arpitasarker01/forkit-ai-footprints/issues/new?template=support_question.yml)
  for installation and usage questions.
- Use the [feature proposal](https://github.com/arpitasarker01/forkit-ai-footprints/issues/new?template=feature_request.yml)
  before building a substantial feature or changing a product boundary.
- Use a private
  [GitHub Security Advisory](https://github.com/arpitasarker01/forkit-ai-footprints/security/advisories/new)
  for security or privacy vulnerabilities.

## What to include

- Forkit AI Footprints version.
- macOS major version, Apple Silicon family, and Node.js major version.
- A minimal reproduction and the expected behavior.
- Redacted screenshots or logs only when they are necessary.

Maintainers may ask for a smaller reproduction or a local validation run.
Public issues are not a channel for urgent security response, private device
forensics, or support for unlisted operating systems.
